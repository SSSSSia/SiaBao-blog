# 数学公式测试

## 行内公式
爱因斯坦质能方程：$E = mc^2$

二次方程求根公式：$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

勾股定理：$a^2 + b^2 = c^2$

## 块级公式
欧拉公式（被誉为最美数学公式）：

$$e^{i\pi} + 1 = 0$$

微积分基本定理：

$$\int_{a}^{b} f(x)dx = F(b) - F(a)$$

矩阵示例：

$$
\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}
$$

求和公式：

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

极限定义：

$$\lim_{x \to \infty} \frac{1}{x} = 0$$

泰勒展开：

$$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n$$

## 代码中的美元符号
这段代码中的 \$ 不会被渲染为公式：

\`javascript
const price = 100;
const total = \$100 + \$50;
console.log(total);
\`

## 测试失败情况
这个公式语法错误，应该显示原文：

$\unclosed{bracket$
