## 二、优化目标

### 2.1 核心目标

- [ ] **P0**: 后台管理页面完整支持移动端
- [ ] **P1**: 前台所有页面在 320px-1280px 范围内完美展示
- [ ] **P1**: 统一响应式断点系统
- [ ] **P2**: 提升无障碍访问性

### 2.2 设计规范

#### 断点标准

```css
/* 响应式断点变量 */
--breakpoint-sm: 640px;   /* 小屏手机 */
--breakpoint-md: 768px;   /* 平板竖屏 */
--breakpoint-lg: 1024px;  /* 平板横屏/小桌面 */
--breakpoint-xl: 1280px;  /* 桌面 */
```

#### 响应式策略

| 屏幕范围 | 布局策略 | 导航方式 |
|---------|---------|---------|
| < 640px | 单列堆叠 | 抽屉/汉堡菜单 |
| 640px - 768px | 单列优化 | 底部标签栏/抽屉 |
| 768px - 1024px | 双列自适应 | 侧边栏可折叠 |
| > 1024px | 多列完整 | 侧边栏展开 |

## 三、分阶段任务清单

### 🎯 Phase 1: 后台管理响应式（P0 - 紧急）

**预计时间：2-3天**

#### Task 1.1: Admin 布局响应式改造

**文件：** [src/pages/Admin/Admin.css](src/pages/Admin/Admin.css)

**问题：**
- 侧边栏固定 250px，移动端占满全屏
- 主内容区域 `margin-left: 250px`，移动端被推出屏幕
- 无移动端导航切换

**解决方案：**
```css
/* 添加移动端抽屉导航 */
@media (max-width: 768px) {
  .admin-sidebar {
    transform: translateX(-100%);
    transition: transform 0.3s ease;
    z-index: 1000;
  }

  .admin-sidebar-open {
    transform: translateX(0);
  }

  .admin-main {
    margin-left: 0;
  }

  .admin-mobile-toggle {
    display: flex;
  }
}
```

**修改文件：**
- [ ] `src/pages/Admin/Admin.css` - 添加响应式样式
- [ ] `src/pages/Admin/Admin.jsx` - 添加移动端切换逻辑

#### Task 2.1: 前台 Sidebar 响应式处理

**文件：** [src/components/layout/Sidebar.css](src/components/layout/Sidebar.css)

  .layout-sidebar-open {
    transform: translateX(0);

### 🎯 Phase 3: 组件响应式标准化（P1）

**预计时间：1天**

#### Task 3.1: 建立统一断点系统

**新建文件：** `src/styles/responsive.css`

```css
:root {
  --breakpoint-sm: 640px;
  --breakpoint-md: 768px;
  --breakpoint-lg: 1024px;
  --breakpoint-xl: 1280px;
}

/* 响应式混用宏（通过 CSS 类） */
@media (max-width: 640px) {
  .hide-sm { display: none !important; }
  .block-sm { display: block !important; }
  .flex-sm { display: flex !important; }
}

@media (max-width: 768px) {
  .hide-md { display: none !important; }
  .block-md { display: block !important; }
  .flex-md { display: flex !important; }
}
```

## 四、技术约束

### 4.1 必须遵守

1. **不破坏现有视觉风格** - 极简黑白灰艺术风格
2. **保持代码一致性** - 遵循现有命名规范
3. **渐进增强** - 移动端优先，向上扩展
4. **性能优先** - 避免过度使用 JavaScript

### 4.2 技术栈

- CSS 原生媒体查询（不引入 Tailwind/Bootstrap）
- React Hooks（useState, useEffect, useRef）
- CSS 变量（已建立）
- CSS clamp()（流体字体）
